# BD outbox

Ready-to-send drafts for Noah. **Noah sends; nothing here is ever sent by a session.**

Since Oct 3, 2026, every email draft is **also created in Gmail Drafts**, as an in-thread reply where there is a thread, so Noah can open Drafts and press send. These files are the record. Web-form text lives only here.

File naming: `YYYY-MM-DD-<church-or-person>-<purpose>.md`. Each file holds: To, (Cc), Subject, Body, plus a one-line "why now." After Noah sends, Sonny moves the file to `work/bd/outbox/sent/` on the next pipeline check (after confirming in the inbox) and updates the tracker.
